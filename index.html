COMPORTEMENT NATIF PRIME AGENT

Modèles par défaut

Le choix principal utilise les réglages globaux defaultProvider et defaultModel. Prime Agent 0.9.1 ne définit pas de modèle global distinct pour les sous-agents. Ils héritent du modèle de leur parent, sauf si l’agent demande explicitement un autre modèle lors d’un appel rlm(…, model=…).
